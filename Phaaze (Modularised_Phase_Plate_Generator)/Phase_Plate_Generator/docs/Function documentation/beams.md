# `beams.py`

[View source](../../src/phase_plate_generator/beams.py)

## Purpose

This module constructs the real, non-negative incident field amplitude
`A(x,y)` on the physical plate grid. The complex near field used later is

```text
U(x,y) = A(x,y) exp(i phi(x,y)).
```

`normalise_beam_name()` maps user aliases to canonical names.
`build_input_amplitude()` returns the amplitude, Boolean pupil and sample pitch
`dx_m = plate_size_m / samples`.

## Numerical recipes

The centred coordinate axis is generated by `optics.centered_axis`; the chosen
beam is then clipped by either a circular or square pupil.

For `circular_gaussian`, with `w = fill_factor * plate_size_m / 2`,

```text
A(x,y) = exp[-(x^2 + y^2)/w^2].
```

This is an **amplitude** Gaussian, so the corresponding intensity is
`exp[-2 r^2/w^2]`.

For `square_supergaussian`,

```text
A(x,y) = exp[-(|x|/w)^(2m) - (|y|/w)^(2m)],
```

where `m = supergaussian_order`. Separability gives a square, flat-topped
profile as the order increases.

For `array`, a finite two-dimensional NumPy array is bilinearly resampled,
negative values are clipped, and the peak is normalised to one. The file is
interpreted as **amplitude**, not intensity. If the measured data are
intensity, the caller must supply their non-negative square root.

## Physics and limitations

The Gaussian convention is compatible with the standard TEM00 transverse
field convention. Super-Gaussians interpolate between a Gaussian-like profile
and a flat top; a common optical definition is discussed by
[Li (2002)](https://doi.org/10.1016/S0030-4018(02)01412-8).

No incident phase aberration is included here. An imported initial phase can
seed the retrieval later, but it is not treated as a measured complex input
beam. Clipping at the pupil creates diffraction and is therefore part of the
model, not merely a plotting mask.

## Units and checks

- `plate_size_m`, `width_m` and `dx_m`: metres.
- Returned amplitude: dimensionless, peak at most one.
- `fill_factor` is a width-to-half-plate-size ratio.
- Imported arrays must be finite, two-dimensional and contain positive power
  after clipping.
